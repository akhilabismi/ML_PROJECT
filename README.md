# Customer Churn Prediction and Analysis

## Project Overview
This project predicts telecom customer churn using Machine Learning. The objective is to identify customers who are likely to leave the service based on customer behavior, contract details, and service usage patterns.


## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn


## Project Workflow
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- Feature Engineering
- Logistic Regression Modeling
- Model Evaluation


## Key Insights
- Customers with month-to-month contracts showed higher churn rates.
- Customers with shorter tenure were more likely to churn.
- Customers using multiple services were less likely to churn.
- Electronic check users showed higher churn behavior.


## Model Performance
- Accuracy: 81%
- Precision: 67%
- Recall: 54%


## Conclusion
The project demonstrates how machine learning can be used to predict customer churn and support data-driven customer retention strategies.
